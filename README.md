# Практические работы по C++

Коллекция практических работ по C++: классы, наследование, полиморфизм,
перегрузка операторов и стандартные контейнеры. Тематика проекта — книги,
библиотека и геометрические фигуры.

Каждая практическая находится в отдельной ветке. Откройте ветку, чтобы
увидеть её исходный код и пояснения к программе.

## Как скачать и запустить проект

### 1. Установите инструменты

- **Windows:** установите Visual Studio Community с компонентом «Разработка
  классических приложений на C++» (включает компилятор MSVC) либо
  MinGW-w64 (`g++`).
- **Linux:** установите `g++` из менеджера пакетов, например
  `sudo apt install g++`.
- **macOS:** установите компилятор командой `xcode-select --install`
  (работает и `clang++`).

### 2. Склонируйте репозиторий

```bash
git clone <ссылка-на-ваш-репозиторий>
cd book-app
git switch practise-8
```

Вместо `practise-8` укажите нужную ветку. Ветка `main` содержит этот обзор;
исходники практических находятся в соответствующих ветках.

### 3. Соберите и запустите из терминала

Для каждой практической берите `main.cpp` и файлы реализации из таблицы
«Ветки и темы»:

```bash
# Например, practise-8
g++ -std=c++17 -Wall -Wextra book.cpp library.cpp main.cpp -o practice
./practice
```

На Windows в PowerShell запустите `.\practice.exe`. Если команда `g++`
не найдена, сначала установите компилятор и перезапустите терминал.

### 4. Запуск в VS Code

1. Выберите **Файл → Открыть папку** и откройте папку репозитория.
2. Убедитесь, что выбрана нужная ветка (её имя видно в левом нижнем углу).
3. Откройте встроенный терминал (**Терминал → Создать терминал**) и
   выполните команду сборки из пункта 3.

### 5. Запуск в Visual Studio (Windows)

1. Создайте **Консольное приложение** на C++.
2. Через правый клик на **Исходные файлы → Добавить → Существующий элемент**
   добавьте `.cpp`-файлы выбранной практической, заголовки `.h` — в
   **Файлы заголовков**.
3. Нажмите **Отладка → Запуск без отладки** (`Ctrl+F5`).

### 6. Запуск в Xcode (macOS)

1. Создайте проект **macOS → Command Line Tool** с языком **C++**.
2. Добавьте в него `.cpp`- и `.h`-файлы выбранной практической.
3. В **Build Settings → C++ Language Dialect** выберите **C++17**.
4. Запустите проект кнопкой ▶ или `⌘R`.
