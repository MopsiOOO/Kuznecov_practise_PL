# Book Library — учебный проект на C++

Набор учебных практик по основам C++: классы, наследование, полиморфизм,
перегрузка операторов и стандартные контейнеры. Тематика проекта — книги
и библиотека.

## Содержимое

Каждая практика лежит в отдельной ветке и покрывает свою тему:

| Ветка | Тема |
|---|---|
| `main` | Практика 1: класс `Book`, конструктор, валидация данных через исключения |
| `practise-2` | Геттеры/сеттеры, свободные функции `formatBookInfo`, `isClassic` |
| `practise-3` | Передача аргументов: по значению, по ссылке, по указателю, const-ссылки |
| `practise-4` | Наследование: класс `RareBook` с оценочной стоимостью |
| `practise-5` | Полиморфизм: виртуальные методы, `override`, класс `Ebook` |
| `practise-6` | Перегрузка операторов: класс `Vector2D` (+, -, *, ==, <, << и др.) |
| `practise-7` | Абстрактные классы: иерархия `Shape` → `Circle`, `Rectangle`, `Triangle`; `Vector3D` |
| `practise-8` | `std::array` и `std::vector`: класс `Library` с динамическим хранилищем книг |

## Сборка и запуск

Требуется компилятор с поддержкой C++17 (g++ или clang++).

```bash
# Из любой ветки — собираются все .cpp-файлы ветки
g++ -std=c++17 -Wall -Wextra *.cpp -o app
./app
```

> В ветке `practise-8` состав фиксированный: `book.cpp library.cpp main.cpp`.

## Структура (ветка practise-8)

- `book.h` / `book.cpp` — класс `Book`: название, автор, год, страницы,
  статус доступности, проверка корректности данных
- `library.h` / `library.cpp` — класс `Library`: хранение книг в `std::vector`,
  добавление/удаление, вывод через `operator<<`
- `main.cpp` — демонстрация: C-style массивы vs `std::array` vs `std::vector`,
  безопасный доступ через `.at()` с обработкой `std::out_of_range`
